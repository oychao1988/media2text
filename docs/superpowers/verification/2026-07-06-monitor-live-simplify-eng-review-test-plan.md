## Affected Flows

- `media2text monitor watch --daemon` — live probe, recording start, offline finalize
- `media2text monitor watch` (single round) — must match one daemon tick after P2
- Desktop daemon card / creator live status lights
- HLS segment upload + post-process summarize

## Key Interactions to Verify

- Creator goes live → recording starts within ~30s (G1)
- Creator goes offline → `live_ended` then `recording_completed` within 60s
- Post-process backlog during live → `post_process_deferred_for_live_lane` still logged
- Daemon restart mid-recording → session recovery + STT bootstrap
- Legacy session in DB only → finalize completes without new legacy sessions

## Edge Cases

- STT degraded → `_streaming_legacy_finalize` path still works until P1 legacy removal scoped
- SQLite lock under load → `test_db_lock_stress` passes after gateway-only migration
- Desktop with external CLI daemon → `managed_by=external` unchanged
- `reconciler_log_only` removal → shadow mode tests removed or replaced

## Critical Paths (E2E / integration)

1. Add creator → monitor on → daemon → live → stop → transcript + summary exist
2. HLS: segment files uploaded, local deleted per config
3. Phase 3: inline `LiveLoop.decide()` — no duplicate prepare from reconcile + inline
